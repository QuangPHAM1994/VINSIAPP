# VINSI APP

Kênh phát hành phần mềm của **CÔNG TY TNHH TƯ VẤN THIẾT KẾ VÀ XÂY DỰNG VINSI**.

- **VINSI HUB**: trình cài đặt và cập nhật phần mềm VINSI. Tải `VINSI_Hub_Setup_*.exe` ở mục **Releases** (tag `hub-v…`), cài rồi mở VINSI HUB để cài các phần mềm khác.
- **VQS – VINSI QUANTITY REBAR & STEEL**: thống kê cốt thép & thép hình (tag `vqs-v…`).
- **VINSI PLOTTER (VPA)**: plugin in / xuất bản vẽ AutoCAD (tag `vpa-v…`).

Repo này chỉ chứa file đã build và danh mục `catalog.json` (có chữ ký `catalog.sig`) để VINSI HUB đọc. Phần mềm cần key bản quyền theo mã máy; dùng thử 3 ngày.
